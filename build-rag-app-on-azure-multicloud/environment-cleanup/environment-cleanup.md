# Clean Up the Environment

## Introduction

Remove the resources created in a regular Azure account to stop further charges. Oracle-provided event resources are removed automatically after the event.

### Objectives

* Identify the resources created for the workshop.
* Remove regular-account resources that are no longer required.

Estimated Time: 5 minutes

## Task 1: Review and remove workshop resources

After you complete the RAG workshop, remove the resources that you created in your account to stop incurring costs. If you are using OCI provided **Azure Event Account**, resources are automatically deleted when the event ends. This section walks you through the list of resources created in your account if you are using **Azure Regular Account**.

1. Azure Machine Learning Workspace Notebooks

2. Azure Machine Learning Workspace Compute

3. Azure Machine Learning Workspace

4. Azure OpenAI Deployments

5. Azure OpenAI

6. Oracle Autonomous AI Database

7. Azure VNET and Subnets
