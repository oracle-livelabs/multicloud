# Clean Up Your Environment

## Introduction

Remove the resources created in your Azure subscription to stop further charges.

### Objectives

* Identify the resources created for the workshop.
* Remove resources that are no longer required.

Estimated Time: 5 minutes

## Task 1: Review and remove workshop resources

After you complete the workshop, remove these resources from your Azure subscription:

1. Azure Machine Learning Workspace notebooks

2. Azure Machine Learning Workspace compute

3. Azure Machine Learning Workspace

4. Azure OpenAI deployments

5. Azure OpenAI

6. Oracle Autonomous AI Database

7. Azure virtual network and subnets
