# Clean Up the Event Environment

## Introduction

Oracle removes the temporary event resources after the workshop ends.

### Objectives

* Understand how the temporary workshop resources are retired.
* Avoid deleting shared resources during the event.

Estimated Time: 2 minutes

## Task 1: Review the event cleanup process

The Azure subscription and its workshop resources are temporary. Oracle removes them after the event ends. No manual cleanup is required unless your workshop instructor gives different instructions.
